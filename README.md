# 🩺 Doctor-Patient Management System

A software application designed to support doctor and patient management, demonstrating core software engineering concepts and structured application development.

## 📌 Overview

The Doctor-Patient Management System is a project focused on organizing interactions and information related to doctors and patients. It provides a foundation for managing healthcare-related data through a dedicated software application.

The project was developed to apply programming concepts, software design principles, and problem-solving techniques to a practical healthcare management scenario.

## ✨ Features

- **Doctor Management:** Organize and manage doctor-related information.
- **Patient Management:** Maintain and manage patient-related information.
- **Healthcare Data Organization:** Structure information related to doctors and patients.
- **Modular Application Design:** Organize functionality into manageable components.
